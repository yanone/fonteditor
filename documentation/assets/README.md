# Documentation Image Assets

This folder stores the screenshots and annotated variants used throughout the user documentation. The goal is to keep visual examples consistent, easy to update, and easy to map back to the relevant page text. If you capture images in a structured way here, future documentation updates remain fast and predictable.

## Recommended File Naming

`<section>-<page>-<index>-<slug>.png`

Examples:

- `getting-started-03-01-main-workspace.png`
- `files-02-02-reenable-disk-access.png`
- `ai-03-01-subscription-gate.png`

## Annotation Guidance

- Keep one clean screenshot and one annotated screenshot if needed.
- Prefer numbered callouts (1, 2, 3...) with a small legend below image.
- Highlight only what the page explains; avoid visual clutter.
- Use short labels that beginners understand.

## Alt Text Guidance

Each image in docs should include concise alt text describing:

1. Where in the app the screenshot is.
2. What action or state is shown.
3. The key UI element the reader should notice.
