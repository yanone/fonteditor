# Files view

The Files view is where sources enter and leave Counterpunch, and where storage context is defined. Getting this right early prevents a lot of “where did that save go?” confusion.

Counterpunch has two storage contexts:

- **Memory** is in-browser storage for quick experiments and temporary work.
- **Disk** is a local folder you grant permission to, for production sources.

![Files view with Memory and Disk contexts](images/files-view.png)

Check which context is active before you save. Open a font from the tree, edit, then save back to the same place. Disk setup is in [Local disk access](02-local-disk-access.md). The Disk folder is not the Settings Folder; both are in [Project and settings folders](../getting-started/04-project-and-settings-folders.md). Formats are in [Open, save, and file formats](03-open-save-formats.md).
