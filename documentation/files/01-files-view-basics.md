# Files View Basics

The Files view is the operational center for how your source files enter and leave Counterpunch. It is also where storage context is defined, which directly affects how safely and predictably your project updates are written. Spending time here early prevents many common beginner mistakes around missing files and uncertain save targets.

## Summary

The Files view is where you open fonts, control where your work is stored, and switch between in-browser memory and local disk folders. A clear mental model of these storage contexts is essential for reliable daily work, especially when moving between quick experiments and production sources.

## Core Concepts

- **Memory**: in-browser storage for quick experiments.
- **Disk**: direct access to a local folder when permission is granted.

## Typical Tasks

1. Open a font from a folder.
2. Check where your current file lives (Memory or Disk).
3. Save changes back to the same location.
