# Your First Session

Your first session should focus on building a reliable editing loop rather than learning every panel at once. The objective is simple: open a font, make a controlled edit, confirm that the change is visible, and save safely. Once this loop feels familiar, the rest of the application becomes much easier to learn.

## Summary

This page walks a new user from launch to first successful save in a short, structured workflow. It emphasizes predictable steps and small edits so beginners can validate their setup and gain confidence before moving into advanced features.

## Before You Begin

- Use a Chromium-based browser for best compatibility.
- Prepare one sample font source file (for example `.glyphs` or `.babelfont`).

## Quick Start Checklist

1. Open Counterpunch.
2. Go to **Files** view.
3. Choose a source file and open it.
4. Switch to **Editor** view and make one visible edit.
5. Save your work.

## Beginner Tips

- Save often when trying new operations.
- Use small edits first to verify your workflow.
- If a panel is unfamiliar, keep going and use the workspace tour next.
