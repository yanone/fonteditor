# Glyph Overview Basics

The Overview view is your high-level inspection surface for the font as a system rather than one glyph at a time. It is especially useful when you need to scan consistency, locate outliers, and plan targeted editing passes. Beginners often improve faster once they alternate between micro-editing in Editor and macro-inspection in Overview.

## Summary

Overview helps you inspect many glyphs at once, search quickly, and choose the next meaningful edit with context. It turns large character sets into manageable visual batches so quality control is less overwhelming.

## Main Actions

The Overview view supports several navigation and selection operations. You can search for glyphs by name, adjust thumbnail size to balance broad scanning with detail inspection, and select one or multiple glyphs for further work. Selected glyphs can be opened directly in the Editor for detailed refinement.
